# Statistical Data Analysis: Titanic Survival Records

A data science pipeline utilizing Python and Pandas to evaluate demographic factors influencing historical survival rates and generate custom statistical data visualizations.

### 📈 Project Roadmap & Backlog
* **Origin:** Developed during middle school (6th/7th grade) to learn exploratory data analysis (EDA).
* **Current Status:** Retained as a foundational portfolio piece showing data manipulation skills.
* **Next Steps:** Planning a 3–4 month math and programming revision sprint to enhance the predictive logic, apply modern styling to the visual plots, and clean up the dataset processing.
